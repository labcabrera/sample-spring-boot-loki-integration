# Normas para usar IA en este proyecto

## Objetivo general

- Este proyecto es ejemplo de arquetipo Java.
- Priorizar código limpio, legible y testeable frente a soluciones “hacky”.
- Todo el codigo y comentarios serán en inglés.

## Estilo de código

- No cambiar el estilo existente si no es necesario.

## Tests

- No añadir test a menos que se indique esa opción.

## Seguridad

- Nunca inventar contraseñas, claves API ni secretos.

## Cómo quiero las respuestas de la IA

- No crear ficheros explicativos md a menos que se indique explicitamente.
- Explicar brevemente el cambio antes de mostrar el código.
- Si la respuesta es larga, dividir en pasos numerados.
- Cuando modifiques archivos, indicar: archivo + cambios clave.
