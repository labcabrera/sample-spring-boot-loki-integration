= Spring Boot WebFlux DDD Archetype

== Estructura

El proyecto utiliza clean architecture y DDD para estructurar el código en capas y módulos bien definidos:

----
src/
 ├── sample-loki-api
 │   ├── src/main/java/org/labcabrera/sample/loki
 │   │   ├── application
 │   │   │   ├── service
 │   │   │   └── dto
 │   │   ├── domain
 │   │   │   ├── model
 │   │   │   └── repository
 │   │   └── interfaces
 │   │       ├── http
 │   │       └── config
 │   └── src/test/java/org/labcabrera/sample/loki
 │       └── ...
 └── sample-loki-infra
     ├── src/main/java/org/labcabrera/sample/loki/infra
     │   ├── logging
     │   └── monitoring
     └── src/test/java/org/labcabrera/sample/loki/infra
         └── ...
----


== Ejecutar la demo

En primer lugar iniciamos minikube a través del script `minikube-install.sh` que crea una instancia de Minikube con
el perfil `sample-loki`:

[source,bash, title="minikube-install.sh"]
----
minikube start \
  --profile "$MINIKUBE_PROFILE" \
  --driver=docker \
  --memory=$MINIKUBE_MEMORY \
  --cpus=$MINIKUBE_CPUS \
  --disk-size=$MINIKUBE_DISK \
  --kubernetes-version=$K8S_VERSION

minikube addons enable metrics-server --profile "$MINIKUBE_PROFILE"

minikube addons enable ingress --profile "$MINIKUBE_PROFILE"

kubectl create namespace "$NAMESPACE_APPS"
kubectl create namespace "$NAMESPACE_OBSERVABILITY"
kubectl create namespace "$NAMESPACE_CERT_MANAGER"
----

A continuación crearemos el certificado usado por el _cert-manager_ a través del script `create-root-certificate.sh`:

[source,bash, title="create-root-certificate.sh"]
----
openssl genrsa -out "$CA_KEY" 2048

openssl req -x509 -new -nodes \
  -sha256 \
  -days 3650 \
  -key "$CA_KEY" \
  -out "$CA_CERT" \
  -subj "/CN=*.local"
----

Una vez creado el certificado, instalamos el _cert-manager_ a través del script `install-cert-manager.sh`:

[source,bash, title="install-cert-manager.sh"]
----
kubectl apply -f https://github.com/cert-manager/cert-manager/releases/latest/download/cert-manager.crds.yaml

helm repo add jetstack https://charts.jetstack.io

helm repo update

helm install cert-manager jetstack/cert-manager \
  --namespace "$NAMESPACE_CERT_MANAGER" \
  --version "$CERT_MANAGER_VERSION"

kubectl create secret tls sample-root-ca \
  --cert="$ROOT_CA_CERT" \
  --key="$ROOT_CA_KEY" \
  -n "$NAMESPACE_CERT_MANAGER"

kubectl apply -f "$ISSUER_CERT"
----

A continuación instalamos ArgoCD a través del script `install-argocd.sh`:

[source,bash, title="install-argocd.sh"]
----
helm install argocd argo/argo-cd \
  --namespace "$NAMESPACE" \
  -f config/argocd-values.yaml
  
find ../argocd -name "*.yaml" -o -name "*.yml" | while read -r file; do
  kubectl apply -f "$file" -n "$NAMESPACE"
done
----

== Probando la aplicación

En primer lugar accederemos a la interfaz de nuestra API en local:

http://localhost:8081/webjars/swagger-ui/index.html

[source,bash]
----
curl -X POST http://localhost:8081/api/v1/counters/foo

curl http://localhost:8081/api/v1/counters

----
